Relationships

—users (1) —→ (N) problems : each report belongs to a citizen
—users (1, response team) —→ (N) problems.assigned_to : problem assigned to a team
—problems (1) —→ (N) deleted_problems : soft-deleted archive snapshot
—users (1) —→ (N) unban_requests : appeals (cascade delete)
—users (1) —→ (N) warnings : target user; admin_id is the issuing admin
—problems + users —→ (N) feedbacks : one rating per user per problem
—problems + users —→ (N) logs : audit trail (SOS triggers, notifications)
